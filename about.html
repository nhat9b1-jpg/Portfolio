Option 2: How I Customized the Base Template

Starting from Start Bootstrap – Freelancer (originally a single-page Bootstrap landing page), I made five major architectural upgrades to match my Week 2 Design Sketch:

  • Multi-Page Refactor: Split the single-page layout into 4 linked HTML5 documents with clear active states.
  • Custom CSS Grid & Mobile-First CSS: Replaced heavy Bootstrap grid wrappers with lightweight native CSS Grid and 3 responsive breakpoints.
  • High-Contrast Accessible Palette: Upgraded low-contrast teal buttons to WCAG AAA Slate/Cobalt and added persistent Dark Mode.
  • Week 3 Extras Implemented: Sticky Footer, Font Awesome 6 icons, JavaScript category filtering, and an accessible HTML5 <dialog> Lightbox modal.
  • Accessibility Hardening: Added Skip Navigation links, keyboard focus rings, strict heading hierarchy, and prefers-reduced-motion support.
